# 期初数据导入

飞书资料用于开账时补齐历史数据，也可由管理员在需要时补录。已保存的订单、退款、库存和采购归档可在对应工作区查询。导入会保存原始时间与历史变更，采购归档会记录上传人，订单导入同时写入操作审计。日常库存由 ERP 仓库收货、发货和盘点等动作记账，新增线上订单由店铺授权连接处理。

## 导入文件

| 资料 | 文件 | 接收入口 | 成功回执 |
| --- | --- | --- | --- |
| 九店历史订单和退款 | `sync-feishu-nine-store-orders.py` 生成的规范 JSON，最大 2,500,000 字节 | `POST /api/nine-store-orders/import` | `observedAt`、`replayed` |
| 历史库存和采购参考 | `sync-feishu-procurement-snapshot.py` 生成的规范 JSON，最大 786,432 字节 | `POST /api/purchase/feishu-preview` | `snapshotDate`、`replayed` |

使用当前公司管理员会话提交完整 JSON 文件，`Content-Type` 为 `application/json`。浏览器提交须与易仓同源。首次有效提交返回 `201`，相同文件重复提交返回 `200`，版本倒退的订单文件返回 `409`。明细保留在各公司的易仓数据库中，仓库库存流水由业务作业单产生。导入处理只读取上传文件。

要生成新的规范文件，可在已有飞书读取授权的本机单次运行对应采集脚本并保存结果，再到易仓上传。采集配置和数据文件应保存在忽略目录，或按公司已有方式保密和备份。

## 期初库存建账

管理员在「期初导入 → 期初库存建账」按 SKU 和仓库审核。系统只接受本工作区已确认库存资料中的同码商品及 CA、GA、NJ 仓库，提交前请核对公司的实际盘点数量和外部预占。确认后通过库存盘点台账登记第一笔仓库余额，记入操作审计。已有库存账的商品仓库可继续使用仓库盘点处理差异。

## 发布设置

本机与新版服务默认使用期初模式。更新后的 Lightsail 发布按这一模式保持已导入数据库，停掉旧的易仓飞书定时服务。其他项目和飞书自身的自动化独立运行。发布后用业务账号确认已导入资料仍可查、旧同步按钮已收起，并用工作区管理员上传经过确认的测试文件。

兼容旧的定时通道需要显式设置 `ERP_FEISHU_MODE=continuous` 并配置专用工作进程。店铺接口和仓库账本运行不依赖该模式。
