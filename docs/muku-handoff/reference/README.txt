Shopify：shopify_yesterday_sales.py 包含请求/令牌/GraphQL/订单行分页/销量及ShopifyQL财务辅助函数；本项目输出仍以汇总为主。ERP必须新增订单持久化和完整状态/退款/履约处理，不能把fetch_sales_range当成订单明细数据库。该代码有适用应用类型和权限要求，按正式官方文档核验。
Wayfair：销售、结算扣款解析器是历史回补/对账逻辑。销售包含Processing；销售与扣款统一识别SZ归属别名。ERP原始单据不得提前剔除。
广告：SP/SB/SD、Shopify、Wayfair WSP 的按内容日期筛选、币种和归属逻辑，仅供财务对账。禁止将广告费推算为订单金额。
YQN：接口客户端及标准化可以移植，但ERP环境仍需单独验证每个生产接口、仓库权限和鉴权。旧标准化函数对未知值的默认处理须重新审查，不将缺字段默认为真实0。
公共规则：SKU匹配、体积、业务日期与来源覆盖率可以参考。单柜装载量/体积和归属映射不能从无依据的别名猜测。
